# 学习通本地学习助手 · v0.1.1

一个本机运行的课程看板，加一个 Chrome / Edge 扩展。采用 Node.js 内置模块，不需要 npm install，不需要学校账号密码，也不需要上传课程数据到 GitHub。

**0.1.1 更新**：补充 HTML5 音频及可见 Video.js 音频控件支持，适用于英语词表等 MP3 章节。音频演示地址为 `http://127.0.0.1:18765/demo?media=audio`。音视频均遵守遇题/验证暂停、前台播放和正常计时规则。

**客户端区别**：学习通 Windows 客户端的登录状态不会自动共享给 Chrome/Edge。本扩展只在浏览器网页生效，不能直接装入学习通客户端。客户端内原生音频已通过桌面播放测试；这不代表扩展与客户端已联通。

## 首次使用

1. 电脑需已安装 **Node.js 22 或更高版本**。在本机下载或解压整个项目。
2. 双击 **`start.cmd`**，保持窗口打开；或在项目文件夹执行 `node server.mjs`。
3. 浏览器打开 [本地课程看板](http://127.0.0.1:18765/)。
4. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。开启「开发者模式」，选择「加载已解压的扩展程序」，选中本项目的 **`extension` 文件夹**。
5. 在看板的「连接你的浏览器」区域，点击「复制本机配对码」。打开浏览器工具栏中的学习助手，展开「连接本地看板」，粘贴配对码，点击「连接并保存」。
6. 在你自己的浏览器里登录学习通，进入课程视频页并刷新一次。点击扩展的「开始 / 处理后继续」。若浏览器阻止自动播放，亲自点击播放器的播放按钮。

先在看板点击 **「体验演示课程」**，可以用 12 秒的本机静音测试媒体验证播放、自动下一节、题目检测和验证暂停，不必先登录学校网站。

## 已实现

| 功能 | 行为 |
|---|---|
| 播放辅助 | 只调用页面原生 `video.play()` / `pause()`；浏览器限制播放时提示人工操作。 |
| 自动下一节 | 在扩展中勾选开关；视频自然结束、未检测到题目或验证、页面位于前台时，点击唯一可识别的可见「下一节」按钮。每章节只尝试一次。 |
| 多层页面 | 在已声明的超星/学习通域名下的匹配 iframe 中观察视频和题目，用顶层页面的课程、章节信息归档。 |
| 本地进度 | 记录已访问课程、章节、视频当前位置和正常播放时长。不会修改学校平台的完成状态。 |
| 题目整理 | 检测常见作业/章节题容器，保存文字并暂停辅助。不完整的图片、公式、附件请回原页核对。 |
| AI 学习草稿 | 由你在看板逐题确认后生成，含答案建议与简要解题依据；不会填写或提交学校页面。 |
| 离线缓存 | 本地服务关闭时，扩展暂存最多 200 条观察事件；恢复后重试。超限丢弃最早记录，不能保证恢复全部时长。 |
| 导出和清空 | 看板可下载本机 JSON 记录，或输入确认文字后清空。运行中的扩展会继续产生新记录。 |

扩展初始关闭；每个课程标签页需要你主动启动。切到后台时会暂停辅助播放，回到前台后请自行播放。正常暂停不会被持续强行恢复。遇题目、登录或验证时，会锁定暂停；请在原页面处理完，再点击扩展的「开始 / 处理后继续」。在看板「标记已核对」只改变本地状态，不会解锁原页或提交任何内容。

## 可选：启用 AI

不配置密钥也能使用播放、记录和题目整理功能。需要 AI 草稿时：

1. 将项目根目录的 `.env.example` 复制为 `.env`。
2. 在你自己的编辑器中填写 `OPENAI_API_KEY`。不要把密钥发到聊天或写入源码。
3. 可通过 `OPENAI_MODEL` 指定你的账户可用的模型；默认 `gpt-4.1-mini`。
4. 停止并重新启动本地服务，在看板逐题勾选发送确认，再点击「生成学习草稿」。

```dotenv
OPENAI_API_KEY=你的密钥
OPENAI_MODEL=gpt-4.1-mini
```

服务仅调用固定的 OpenAI Responses API 地址。题干作为不可信数据发送，无工具执行能力；请求设置 `store: false`。只有你主动选择的该题文字会随该次请求发送，密钥只在本地服务使用。API 可能收费，访问也受你的网络和账户权限影响。请求参数参考 [OpenAI 官方文字生成文档](https://developers.openai.com/api/docs/guides/text)，模型信息见 [官方模型说明](https://developers.openai.com/api/docs/models/gpt-4.1-mini)。

## 页面适配与限制

- 默认识别通用 HTML5 视频、常见章节标题与题目容器。真实学校页面可能不同，本版未登录你的学校平台实测。
- 若课程名或章节名识别不准，可在扩展「页面适配」中填入相应的 CSS 选择器；保存后刷新课程页。填写错误会使识别失败，清空可恢复默认。
- 「下一节」必须是唯一、可见、非提交控件，文字须为「下一节」「下一章」「下一章节」「下一个视频」或 `Next chapter`；链接需同源。不能识别时请手动切换。不会自动遍历整门课的目录。
- 依赖站点内部 JavaScript、不同域名播放器、封闭 Shadow DOM、非 HTML5 视频或多个连续视频的复杂页面，可能需要专门适配。本版不读取跨域受限内容，不访问平台私有学习记录接口。
- 课程和章节 ID 尽量取页面已公开的 URL 参数，未识别时按标题归档；课程结构变化可能出现分组不准确或重复记录。本机统计仅覆盖访问过的内容，不代表整门课的总进度。
- 不包含自动答题提交、伪造学习记录、验证码绕过、隐藏扩展或规避平台检测；无法保证扩展不被平台识别。

## 数据和权限

- 服务仅监听 `127.0.0.1:18765`，不会监听局域网地址；看板和扩展通过随机配对码连接。
- `data/state.json`：本机课程、视频、题目、草稿和已核对状态。
- `data/pairing-token`：本机配对码；扩展也会把配对码保存在自己的存储中。
- `.env`、`data/`、日志、依赖目录均在 `.gitignore` 中，不上传 GitHub。
- 保存的课程链接会去掉常见令牌参数；复制/导出题干前仍应检查个人信息。
- 权限为 `storage`、`alarms`、`activeTab` 和固定本机服务地址；内容脚本限于声明的超星/学习通页面及本机演示页。没有 cookies、浏览器调试、请求拦截或全站访问权限。内容脚本架构参考 [Chrome 官方文档](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)。
- 如需重置配对码：先停止服务，移走 `data/pairing-token` 后重启，在扩展中重新配对。学习记录不受影响。

## 常见问题

**看板打不开**：确认启动窗口未关闭，地址中的端口是 `18765`，并且本机 Node.js 能正常运行。

**提示端口被占用**：先检查是不是已经启动了同一个看板，不要重复启动。若是其他程序占用此端口，需要同时调整服务端口和扩展中的本机地址，并重新加载扩展。

**扩展没发现页面**：确认扩展已开启、已配对，页面是受支持的域名，安装后已刷新课程页，并在当前标签页点击过「开始」。学校使用独立域名时，本版不会注入该页面。

**没有自动播放/自动下一节**：先点一次播放器播放；下一节开关默认关闭，需要勾选并保存。题目、验证、后台标签页、多义按钮和不受支持的播放器都会让辅助停止。

**AI 提示未配置或失败**：检查 `.env` 文件名、密钥、模型权限、额度和网络；修改后必须重启。没有配置时不会伪造 AI 答案。

**停止使用**：关闭启动窗口，在浏览器中暂停或停用扩展。扩展不会自动替你登录。

## 项目结构与检查

```text
extension/      Manifest V3 扩展：弹窗、页面适配、内容脚本、后台同步
public/         本地看板和演示课程
lib/            本机数据整理、AI 请求
server.mjs      无第三方依赖的 HTTP 服务
tests/          数据、配对、安全边界和 AI 请求集成测试
scripts/        语法和扩展入口检查
start.cmd       Windows 启动入口
```

在项目目录运行：

```powershell
node scripts/check.mjs
node --test tests/*.test.mjs
```

本版已在 Windows Node.js 24 环境通过接口/持久化测试，并在独立 Edge 环境中验证了真实加载扩展、演示媒体播放、遇题暂停与同步、人工继续、自然结束切换、验证暂停和桌面/手机宽度布局。AI 请求使用模拟返回测试；未使用真实密钥调用，未登录学校平台验证。
